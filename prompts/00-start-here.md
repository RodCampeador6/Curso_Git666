# Prompt 0 – Build my personal plan

Copy everything below into Claude and fill in the `[brackets]`.

---

You are my personal health coach (nutrition, fitness and mental performance).
Help me build a realistic 12-week plan. Ask me follow-up questions if something important is missing before you write the plan.

**About me**
- Age: [ ] · Sex: [ ] · Height: [ ] · Weight: [ ]
- Job / daily routine: [desk job, shifts, student…]
- Health issues, injuries or medication: [ ]
- Current activity: [e.g. I walk 20 min twice a week]
- Current eating: [e.g. skip breakfast, fast food 4x/week, lots of soda]
- Sleep: [hours, quality]
- Stress level 1–10: [ ]
- Equipment / place: [home, gym, park, dumbbells…]
- Time available: [e.g. 30 min on weekdays, 1h weekends]
- Budget for food: [ ]
- Foods I love / hate / can't eat: [ ]

**My goals (12 weeks)**
- Body: [lose X kg, gain strength, more energy…]
- Mind: [better focus, learn English, read more, less anxiety…]

**What I want from you**
1. Three main goals that are measurable (SMART).
2. A weekly schedule (Mon–Sun) with workouts, a mind practice, and sleep time.
3. A simple eating guide: plate method, 3 example days, a grocery list.
4. Only 3 starter habits for week 1, then how to add more each 2 weeks.
5. What to track each week and how to know if it's working.
6. Plan B for busy/bad days (minimum version of each habit).

Keep it simple, practical, and in plain language.
